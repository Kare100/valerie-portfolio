# Valerie Mwangi · Portfolio

My personal portfolio: a scroll-through story of how I went from finance to building AI-powered mobile and
web products as a software engineer in Nairobi.

**Live site:** <https://valerie-portfolio-chi.vercel.app>

## What's on it

* **The story:** the turning points, from the sensible degree to shipping with real teams
* **Selected projects:** Fundi Notes, RIELA Connect, SNDBX Experts, Shaba Jewellery, AgriSmart Kenya and my contribution to the Hiero JS SDK
* **Where I've worked**
* **Contact:** email, LinkedIn and GitHub

## How it's built

A single `index.html` with plain HTML, CSS and JavaScript. No framework and no build step.

* Scroll-driven animation using `IntersectionObserver` and `requestAnimationFrame`
* Inline SVG illustrations
* Respects `prefers-reduced-motion` for visitors who turn animation off
* Fonts: Bricolage Grotesque, Inter and JetBrains Mono from Google Fonts

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
